Description: This web page allows you to connect to the ESP32 via BLE and send text to a USB HID keyboard.

Usage:

  1. Connect the USB OTG connector of the USB HID bridge to the target PC.
  2. Click "Connect to ESP32" to establish a BLE connection with the USB HID bridge device you just connected to the target PC. Device name will be in the format "ESP32-HID-XXX".
  3. Enter the text you want to send to the target PC in the textarea.
  4. Optionally, check "Add [↵](Enter) key at the end" to append an Enter key after the text.
  5. Optionally, check "Auto-clear after sending" to clear the textarea after sending.
  6. Click "Send to Target PC" to transmit the text via the ESP32 to the USB HID keyboard.

Preparation:

  • Purchase an ESP32-S3 device
  • Install the flash tool for programming the ESP32-S3 device.
  • Download the firmware sourcecode for the BLE HID bridge device from https://github.com/masaruyokoi/esp32s3_ble_usbhid_bridge .
  • Build the source code and burn the firmware onto the ESP32-S3 device using the `idf.py flash` command.

Troubleshooting:

  • Ensure the ESP32 device is powered on and advertising via BLE before attempting to connect.
  • Make sure the USB HID bridge is properly connected to the target PC.
  • If the connection fails, try refreshing the web page and reconnecting.
  • If you flash the firmware onto the ESP32-S3 device, please operate "forget device" on your PC to remove the previous BLE pairing information. (when flashing new firmware, previous encryption keys is forgotten)
